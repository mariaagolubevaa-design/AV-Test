# Азбука вкуса — UX-прототип

Интерактивный мобильный прототип по макетам Figma.

## Запуск

```sh
npm install
npm start
```

Откройте адрес, указанный сервером. Основной размер макета: 402 × 874 px.

## Сборка

```sh
npm run build
```

## Реализовано

- Главная до и после входа; вход по любым четырём цифрам без отправки SMS.
- Экранная цифровая клавиатура на компьютере, системная клавиатура на телефоне.
- Карточки товаров с горизонтальной прокруткой, избранным и количеством.
- Пересчёт суммы и количества в таббаре.
- Карта выбора адреса и шторка адреса/времени доставки.
- Проверка адреса и времени при добавлении; вибрация при поддержке браузером.

Это демонстрационный прототип: карта использует статичный фон, SMS и реальные заказы не отправляются. Часть экранов пока представлена заглушками; сценарий уменьшения остатков после смены адреса ещё не завершён.

Изображения и иконки хранятся локально в `assets/`. Состояние входа, адрес и время сохраняются в sessionStorage.
